 # PantryAgent

 ## Problem
As a college student, I often find myself planning to make amazing meals (a little overconfident) after I get back from my classes. But two problems consistently rear their head:
 
1. I don't buy the groceries to make what I pictured.
2. I don't know what I can make with the groceries that I have.

## Purpose
The goal of PantryAgent is to assist me in these two steps, so that I can use the unnecessary time that I spend thinking about what groceries I have and how to use them, in actually making food.
